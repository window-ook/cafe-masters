# 추천 카페 기능 테스트 시나리오

## 개요
개발자가 직접 방문하고 추천하는 카페 목록을 카테고리별로 필터링하여 탐색하는 기능을 검증하는 시나리오입니다.

## 우선순위
**High (P1)** - 서비스 차별화 포인트인 큐레이션 기능

## 시나리오 1: 추천 카페 페이지 기본 기능

### 목적
추천 카페 페이지의 기본적인 로딩과 표시 기능이 정상 동작하는지 검증

### 전제조건
- 메인 페이지 접속 상태
- 사이드바에서 "개발자가 추천하는 카페" 메뉴 클릭

### 테스트 단계
1. 추천 카페 페이지(`/recommendation`) 로드 확인
2. 추천 카페 개수 표시 확인 (예: "4개")
3. 카테고리 필터 목록 표시 확인
4. 기본 추천 카페 목록 표시 확인
5. 각 카페 정보 표시 확인:
   - 카페 이름
   - 주소
   - 전화번호
   - 카테고리 태그

### 예상 결과
- 추천 페이지가 빠르게 로드됨
- 추천 카페 총 개수가 정확히 표시됨
- 모든 카테고리 필터가 나열됨
- 기본 상태에서 모든 추천 카페 표시
- 카페별 완전한 정보 제공

### 실패 조건
- 페이지 로딩 실패
- 개수 표시 오류
- 카테고리 목록 누락
- 카페 정보 부정확
- 레이아웃 깨짐

## 시나리오 2: 카테고리 필터링 기능

### 목적
다양한 카테고리별로 추천 카페를 필터링하는 기능이 정확히 동작하는지 검증

### 전제조건
- 추천 카페 페이지 접속 상태
- 여러 카테고리에 속한 카페들이 존재

### 테스트 단계
1. **개별 카테고리 필터 테스트**
   - "커피가 맛있는" 카테고리 클릭
   - 해당 카테고리 카페만 표시되는지 확인
   - "디저트가 맛있는" 카테고리로 변경
   - 필터 결과 즉시 변경 확인

2. **다중 카테고리 선택 테스트**
   - 여러 카테고리 동시 선택 가능 여부 확인
   - AND 또는 OR 조건 적용 확인

3. **카테고리 전체 목록 확인**
   - 제공되는 모든 카테고리 확인:
     - 커피가 맛있는
     - 디저트가 맛있는
     - 가격이 합리적인
     - 조용한
     - 시끌벅적한
     - 교통 접근성 좋은
     - 콘센트 많은
     - 의자가 편한
     - 공간이 넓은
     - 전망 좋은
     - 빈티지한
     - 세련된
     - 특색있는
     - 애견 동반 O
     - 밝은
     - 어두운
     - 좋은 냄새 나는
     - 포토존 있는
     - 주차장 있는

4. **필터 초기화**
   - "전체" 또는 필터 초기화 기능 확인
   - 모든 추천 카페 재표시 확인

### 예상 결과
- 선택한 카테고리에 해당하는 카페만 표시
- 필터 변경 시 즉시 결과 업데이트
- 모든 카테고리가 정확히 분류됨
- 다중 선택 시 적절한 로직 적용
- 필터 초기화 기능 정상 동작

### 실패 조건
- 필터링 결과 부정확
- 카테고리 분류 오류
- 필터 변경 시 지연
- 다중 선택 로직 오류
- 초기화 기능 실패

## 시나리오 3: 추천 카페 상세 정보 및 상호작용

### 목적
추천 카페 아이템 클릭 시 상세 정보와 상호작용 기능이 정상 동작하는지 검증

### 전제조건
- 추천 카페 목록 표시 상태
- 특정 추천 카페 선택

### 테스트 단계
1. 추천 카페 아이템 클릭
2. 상세 정보 모달 또는 페이지 표시 확인
3. 상세 정보 내용 확인:
   - 카페 기본 정보
   - 개발자 추천 이유 (있는 경우)
   - 카테고리 태그들
   - 영업시간, 위치 등
4. "수집하기" 버튼 존재 및 동작 확인
5. "북마크" 버튼 존재 및 동작 확인
6. "메뉴 보기" 버튼 동작 확인

### 예상 결과
- 카페 클릭 시 상세 정보 즉시 표시
- 추천 카페만의 특별한 정보 제공
- 카테고리 태그가 명확히 표시됨
- 수집/북마크 기능 정상 동작
- 메뉴 정보 접근 가능

### 실패 조건
- 상세 정보 표시 실패
- 추천 관련 정보 누락
- 상호작용 버튼 동작 실패
- 카테고리 정보 부정확
- 메뉴 정보 접근 불가

## 시나리오 4: 추천 카페에서 수집 플로우

### 목적
추천 카페를 수집하는 과정이 일반 카페 수집과 동일하게 동작하는지 검증

### 전제조건
- 로그인된 사용자 상태
- 추천 카페 상세 정보 표시

### 테스트 단계
1. 추천 카페 상세에서 "수집하기" 클릭
2. 평점 선택 인터페이스 표시 확인
3. 1-5점 중 평점 선택
4. 수집 완료 처리 확인
5. 컬렉션 페이지에서 수집된 카페 확인
6. 수집된 카페에 추천 출처 표시 확인 (옵션)

### 예상 결과
- 추천 카페 수집 플로우가 일반 카페와 동일
- 모든 평점 시스템 정상 적용
- 컬렉션에 정상적으로 추가
- 추천 출처 정보 유지 (있는 경우)

### 실패 조건
- 수집 플로우 차이 발생
- 평점 시스템 오류
- 컬렉션 추가 실패
- 출처 정보 누락

## 시나리오 5: 추천 카페에서 북마크 플로우

### 목적
추천 카페를 북마크하는 기능이 정상적으로 동작하는지 검증

### 전제조건
- 로그인된 사용자 상태
- 추천 카페 목록 또는 상세 정보 표시

### 테스트 단계
1. 추천 카페에서 북마크 버튼 클릭
2. 북마크 추가 성공 피드백 확인
3. 북마크 페이지에서 추가된 카페 확인
4. 북마크된 추천 카페의 카테고리 정보 유지 확인
5. 북마크에서 추천 출처 표시 확인 (옵션)

### 예상 결과
- 북마크 기능이 일반 카페와 동일하게 동작
- 카테고리 정보가 북마크에도 유지
- 추천 출처 정보 보존
- 북마크 목록에서 구분 가능

### 실패 조건
- 북마크 기능 동작 실패
- 카테고리 정보 손실
- 출처 정보 누락
- 북마크 목록 표시 오류

## 시나리오 6: 카테고리 접기/펼치기 기능

### 목적
카테고리 목록의 "접기" 기능이 사용자 경험을 개선하는지 검증

### 전제조건
- 추천 카페 페이지의 카테고리 목록 표시 상태
- "접기" 버튼 존재 확인

### 테스트 단계
1. 전체 카테고리 목록 표시 상태 확인
2. "접기" 버튼 클릭
3. 카테고리 목록 축소 확인
4. 축소된 상태에서 필수 카테고리만 표시 확인
5. "더 보기" 또는 "펼치기" 버튼 표시 확인
6. 펼치기 버튼 클릭하여 전체 목록 복원 확인

### 예상 결과
- 카테고리 목록이 부드럽게 축소/확장
- 축소 시 주요 카테고리만 유지
- 접기/펼치기 상태가 명확히 구분
- 사용자 인터페이스 개선 효과

### 실패 조건
- 접기/펼치기 동작 실패
- 애니메이션 끊김
- 카테고리 선택 상태 초기화
- 레이아웃 깨짐

## 시나리오 7: 추천 카페 상세 페이지 (직접 접근)

### 목적
추천 카페 상세 페이지(`/recommendation/detail/[id]`)에 직접 접근했을 때 정상 동작하는지 검증

### 전제조건
- 추천 카페의 고유 ID 확인
- 직접 URL 접근 가능

### 테스트 단계
1. 추천 카페 상세 페이지 URL 직접 접근
2. 페이지 로딩 및 정보 표시 확인
3. 브라우저 뒤로가기로 추천 목록 복귀 확인
4. 북마크 기능 정상 동작 확인
5. 수집 기능 정상 동작 확인
6. 메뉴 보기 기능 확인

### 예상 결과
- 직접 URL 접근 시 정상 로딩
- 모든 카페 정보 완전히 표시
- 뒤로가기 네비게이션 정상
- 모든 상호작용 기능 정상 동작

### 실패 조건
- 직접 접근 시 페이지 오류
- 정보 표시 불완전
- 네비게이션 문제
- 기능 동작 실패

## 시나리오 8: 추천 카페 성능 및 사용자 경험

### 목적
추천 카페 페이지의 성능과 전반적인 사용자 경험이 만족스러운지 검증

### 전제조건
- 추천 카페 페이지 접속 상태
- 다양한 화면 크기 테스트 환경

### 테스트 단계
1. **페이지 로딩 성능**
   - 초기 로딩 시간 측정 (3초 이내)
   - 카테고리 필터링 응답 시간 확인

2. **반응형 디자인**
   - 모바일에서 카테고리 목록 표시 확인
   - 터치 스크롤 및 필터 선택 확인
   - 카페 목록 모바일 최적화 확인

3. **사용자 경험**
   - 카테고리 필터 직관성 확인
   - 카페 정보 가독성 확인
   - 전체적인 네비게이션 편의성

### 예상 결과
- 빠른 페이지 로딩 및 필터링
- 모든 화면 크기에서 최적화된 경험
- 직관적이고 편리한 사용자 인터페이스
- 개발자 추천의 가치 명확히 전달

### 실패 조건
- 로딩 시간 과도하게 느림
- 모바일 사용성 문제
- 사용자 인터페이스 혼란
- 추천 가치 전달 부족
