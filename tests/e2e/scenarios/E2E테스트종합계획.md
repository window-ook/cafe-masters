# 카페 마스터즈 E2E 테스트 종합 계획

## 🎯 개요

카페 마스터즈(Cafe Masters) 웹 애플리케이션의 모든 핵심 사용자 여정을 검증하기 위한 포괄적인 E2E 테스트 계획입니다. 사용자 관점에서 실제 사용 시나리오를 기반으로 한 테스트 전략을 제공합니다.

## 🗺️ 사용자 여정 맵

### 1. 신규 사용자 여정 (First-Time User Journey)

```
홈페이지 → 회원가입 → 로그인 → 카페 검색 → 카페 수집 → 컬렉션 확인
```

**총 소요 시간**: 약 25분  
**핵심 검증 포인트**: 서비스 가치 인식, 가입 프로세스, 첫 수집 경험

### 2. 일반 사용자 여정 (Regular User Journey)

```
로그인 → 검색/추천 탐색 → 북마크 추가 → 카페 방문 후 수집 → 컬렉션 관리
```

**총 소요 시간**: 약 20분  
**핵심 검증 포인트**: 로그인 편의성, 카페 발견, 수집 플로우

### 3. 파워 사용자 여정 (Power User Journey)

```
로그인 → 고급 필터링 → 다량 북마크 → 대량 수집 → 티어 진행 → 컬렉션 정리
```

**총 소요 시간**: 약 30분  
**핵심 검증 포인트**: 고급 기능, 성능, 대량 데이터 처리

## 🚨 알려진 제한사항 및 고려사항

### 기술적 제한사항

1. **카카오 OAuth**: 테스트 환경에서 실제 카카오 로그인 제한
2. **이메일 발송**: 비밀번호 재설정 이메일 실제 발송 제한
3. **지도 API**: 외부 지도 서비스 의존성
4. **이미지 로딩**: 외부 CDN 이미지 로딩 시간 변동

### 데이터 일관성

1. **검색 결과**: 실시간 데이터 변동 가능성
