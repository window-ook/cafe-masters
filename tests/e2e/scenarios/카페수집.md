# 카페 수집 기능 테스트 시나리오

## 개요
사용자가 방문한 카페를 평점과 함께 수집하여 개인 컬렉션에 추가하는 기능을 검증하는 시나리오입니다.

## 우선순위
**Critical (P0)** - 서비스의 핵심 가치인 카페 컬렉션 기능

## 시나리오 1: 카페 수집 기본 플로우 (로그인된 상태)

### 목적
로그인된 사용자가 카페를 수집하는 전체 과정이 정상적으로 동작하는지 검증

### 전제조건
- 사용자 로그인 완료
- 검색 결과 또는 추천 카페 목록에서 카페 선택
- 카페 상세 모달 표시 상태

### 테스트 단계
1. 카페 상세 모달에서 "수집하기" 버튼 클릭
2. 평점 선택 인터페이스 표시 확인
3. 평점 선택 (1-5점 중 선택)
4. 추가 정보 입력 옵션 확인 (메모, 방문 날짜 등)
5. 수집 완료 버튼 클릭
6. 수집 성공 메시지 또는 피드백 확인
7. 컬렉션 페이지에서 추가된 카페 확인

### 예상 결과
- "수집하기" 버튼이 명확하게 표시됨
- 직관적인 평점 선택 인터페이스 제공
- 선택적 추가 정보 입력 가능
- 수집 완료 후 즉시 피드백 제공
- 컬렉션에 새 카페가 정확히 추가됨

### 실패 조건
- 수집 버튼 동작 실패
- 평점 선택 인터페이스 누락
- 수집 처리 실패
- 피드백 메시지 부재
- 컬렉션 업데이트 실패

## 시나리오 2: 평점별 카드 등급 시스템

### 목적
평점에 따른 카드 등급(Under/Silver/Gold) 시스템이 정확히 적용되는지 검증

### 전제조건
- 로그인된 사용자 상태
- 수집할 카페 선택

### 테스트 단계
1. **Under 등급 테스트 (1-2점)**
   - 1점 또는 2점으로 카페 수집
   - 컬렉션에서 Under 등급 카드 표시 확인

2. **Silver 등급 테스트 (3-4점)**
   - 3점 또는 4점으로 카페 수집
   - 컬렉션에서 Silver 등급 카드 표시 확인

3. **Gold 등급 테스트 (5점)**
   - 5점으로 카페 수집
   - 컬렉션에서 Gold 등급 카드 표시 확인

4. **등급별 시각적 차이 확인**
   - 각 등급의 카드 디자인 차이 확인
   - 등급 표시 아이콘 또는 색상 확인

### 예상 결과
- 평점에 따라 정확한 등급 적용
- 각 등급별 명확한 시각적 구분
- 컬렉션 페이지에서 등급 정보 표시
- 일관된 등급 시스템 적용

### 실패 조건
- 평점과 등급 불일치
- 등급 시각적 구분 부족
- 등급 정보 누락
- 시스템 일관성 부족

## 시나리오 3: 중복 수집 방지

### 목적
이미 수집된 카페를 재수집하려 할 때 적절한 처리가 되는지 검증

### 전제조건
- 이미 수집된 카페가 있는 사용자 계정
- 수집된 카페의 상세 모달 표시

### 테스트 단계
1. 이미 수집된 카페의 상세 정보 접근
2. "수집하기" 버튼 상태 확인
3. 버튼 클릭 시 동작 확인:
   - 중복 수집 방지 메시지 표시
   - 또는 "이미 수집됨" 상태 표시
   - 또는 평점 수정 옵션 제공

### 예상 결과
- 이미 수집된 카페에 대한 명확한 상태 표시
- 중복 수집 방지 또는 적절한 안내
- 기존 수집 정보 표시 (평점, 등급)
- 수정 옵션 제공 (평점 변경 등)

### 실패 조건
- 중복 수집 허용
- 상태 표시 불명확
- 기존 정보 덮어쓰기
- 사용자 혼란 유발

## 시나리오 4: 수집 후 컬렉션 페이지 연동

### 목적
카페 수집 후 컬렉션 페이지에서 올바르게 표시되고 관리되는지 검증

### 전제조건
- 몇 개의 카페를 수집한 사용자 계정
- 컬렉션 페이지 접속

### 테스트 단계
1. 사이드바에서 "내가 수집한 카페" 클릭
2. 컬렉션 페이지 로드 확인
3. 수집된 카페 목록 표시 확인
4. 카페 카드의 정보 확인:
   - 카페 이름
   - 평점 (별표 표시)
   - 등급 (Under/Silver/Gold)
   - 수집 날짜
5. 지역 필터 기능 테스트
6. 별점 필터 기능 테스트
7. 카페 카드 클릭 시 상세 페이지 이동 확인

### 예상 결과
- 수집된 모든 카페가 카드 형태로 표시
- 각 카드에 완전한 정보 표시
- 지역 및 별점 필터 정상 동작
- 카드 클릭 시 상세 페이지 이동
- 3D 회전 효과 등 카드 인터랙션

### 실패 조건
- 컬렉션 페이지 로딩 실패
- 수집된 카페 누락
- 카드 정보 부정확
- 필터 기능 동작 실패
- 상세 페이지 이동 실패

## 시나리오 5: 티어 시스템 진행도

### 목적
카페 수집 개수에 따른 티어 시스템이 정확히 동작하는지 검증

### 전제조건
- 신규 사용자 계정 또는 초기화된 계정
- 여러 카페 수집 가능한 환경

### 테스트 단계
1. 초기 티어 상태 확인
2. 카페 수집 후 티어 변화 확인
3. 수집 개수와 티어 진행도 일치 확인
4. 홈페이지의 "총 수집된 카드 N개" 업데이트 확인
5. 티어업 달성 시 알림 또는 피드백 확인

### 예상 결과
- 수집 개수에 따른 정확한 티어 표시
- 실시간 티어 진행도 업데이트
- 홈페이지 카운터 실시간 반영
- 티어업 시 사용자 피드백 제공

### 실패 조건
- 티어 계산 오류
- 진행도 업데이트 지연
- 카운터 불일치
- 티어업 피드백 부재

## 시나리오 6: 수집 데이터 검증 및 에러 처리

### 목적
수집 과정에서 발생할 수 있는 에러 상황들이 적절히 처리되는지 검증

### 전제조건
- 로그인된 사용자 상태
- 네트워크 및 서버 에러 시뮬레이션 가능

### 테스트 단계
1. **네트워크 연결 불안정 상황**
   - 수집 진행 중 네트워크 차단
   - 에러 메시지 및 재시도 옵션 확인

2. **서버 에러 상황**
   - 서버 응답 지연 또는 에러
   - 적절한 에러 처리 확인

3. **필수 데이터 누락 상황**
   - 평점 선택 없이 수집 시도
   - 유효성 검사 메시지 확인

4. **동시 수집 요청**
   - 빠른 연속 클릭으로 중복 요청
   - 중복 처리 방지 확인

### 예상 결과
- 모든 에러 상황에 대한 명확한 메시지
- 네트워크 에러 시 재시도 옵션 제공
- 필수 입력 검증 적절히 수행
- 중복 요청 방지 메커니즘 동작

### 실패 조건
- 에러 상황 무시 또는 잘못 처리
- 사용자에게 불명확한 피드백
- 중복 데이터 생성
- 시스템 불안정성

## 시나리오 7: 수집된 카페 상세 페이지

### 목적
컬렉션에서 수집된 카페 클릭 시 나타나는 상세 페이지가 정상 동작하는지 검증

### 전제조건
- 수집된 카페가 있는 컬렉션 페이지
- 특정 카페 카드 클릭

### 테스트 단계
1. 컬렉션에서 카페 카드 클릭
2. 수집된 카페 상세 페이지(`/collection/detail/[id]`) 이동 확인
3. 상세 정보 표시 확인:
   - 카페 기본 정보
   - 내가 매긴 평점
   - 수집 날짜
   - 카드 등급
4. "수정하기" 버튼 존재 및 동작 확인
5. "메뉴 보기" 버튼 동작 확인
6. 뒤로가기 네비게이션 확인

### 예상 결과
- 상세 페이지가 올바른 경로로 이동
- 수집된 카페의 모든 정보 표시
- 내 평점 및 수집 정보 명확히 표시
- "수정하기" 기능 정상 동작
- 직관적인 네비게이션 제공

### 실패 조건
- 상세 페이지 접근 실패
- 카페 정보 불일치
- 수집 정보 누락
- 수정 기능 동작 실패
- 네비게이션 문제
