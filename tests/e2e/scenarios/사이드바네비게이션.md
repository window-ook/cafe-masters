# 사이드바 네비게이션 테스트 시나리오

## 개요
메인 페이지의 사이드바를 통한 페이지 간 네비게이션과 관련 기능들을 검증하는 시나리오입니다.

## 우선순위
**Critical (P0)** - 모든 페이지 이동의 핵심 네비게이션

## 시나리오 1: 사이드바 기본 표시 및 구조

### 목적
사이드바가 올바르게 표시되고 모든 메뉴 항목이 정확히 나열되는지 검증

### 전제조건
- 메인 페이지(`/main`) 접속 상태

### 테스트 단계
1. 사이드바 표시 확인
2. 로고 "Cafe Masters" 표시 확인
3. 검색 입력 필드 "GO" 버튼 확인
4. 메뉴 항목들 표시 확인:
   - "검색 결과" (개수 표시 포함)
   - "내가 수집한 카페"
   - "북마크한 카페"
   - "개발자가 추천하는 카페" (개수 표시 포함)
   - "도움 센터"
5. 하단 로그인/로그아웃 영역 확인

### 예상 결과
- 사이드바가 화면 좌측에 고정 표시
- 모든 메뉴 항목이 명확히 구분되어 표시
- 검색 결과 및 추천 카페 개수가 실시간 반영
- 로그인 상태에 따른 적절한 하단 영역 표시

### 실패 조건
- 사이드바 표시 실패
- 메뉴 항목 누락
- 개수 표시 오류
- 레이아웃 깨짐

## 시나리오 2: 검색 기능 (사이드바)

### 목적
사이드바 상단의 검색 기능이 정상적으로 동작하는지 검증

### 전제조건
- 메인 페이지 사이드바 표시 상태

### 테스트 단계
1. 검색 입력 필드 클릭
2. 검색어 입력 (예: "성수")
3. "GO" 버튼 클릭 또는 엔터키 입력
4. 검색 결과 페이지로 이동 확인
5. 입력한 검색어로 결과 표시 확인
6. 사이드바의 "검색 결과" 개수 업데이트 확인

### 예상 결과
- 검색 입력 필드가 포커스 가능
- 검색어 입력 및 제출 정상 동작
- 검색 결과 페이지로 즉시 이동
- 검색 결과가 입력한 키워드와 일치
- 사이드바 개수가 실시간 업데이트

### 실패 조건
- 검색 입력 필드 동작 실패
- 검색 제출 처리 오류
- 페이지 이동 실패
- 검색 결과 불일치
- 개수 업데이트 누락

## 시나리오 3: 메뉴별 페이지 이동

### 목적
사이드바의 각 메뉴 클릭 시 올바른 페이지로 이동하는지 검증

### 전제조건
- 메인 페이지 사이드바 표시 상태

### 테스트 단계
1. **"검색 결과" 메뉴 클릭**
   - `/search` 페이지 이동 확인
   - 검색 페이지 콘텐츠 로드 확인

2. **"내가 수집한 카페" 메뉴 클릭**
   - `/collection` 페이지 이동 확인
   - 컬렉션 페이지 로드 확인

3. **"북마크한 카페" 메뉴 클릭**
   - `/bookmark` 페이지 이동 확인
   - 북마크 페이지 로드 확인

4. **"개발자가 추천하는 카페" 메뉴 클릭**
   - `/recommendation` 페이지 이동 확인
   - 추천 페이지 로드 확인

5. **"도움 센터" 메뉴 클릭**
   - `/help` 페이지 이동 확인
   - 도움말 페이지 로드 확인

### 예상 결과
- 모든 메뉴가 올바른 페이지로 이동
- 페이지 이동 시 URL 변경 확인
- 각 페이지의 콘텐츠가 정상 로드
- 현재 페이지 메뉴 하이라이트 (선택 상태 표시)

### 실패 조건
- 메뉴 클릭 동작 실패
- 잘못된 페이지로 이동
- 페이지 로딩 실패
- 현재 페이지 표시 누락

## 시나리오 4: 로그인 상태별 처리

### 목적
로그인 상태에 따라 사이드바와 페이지 접근이 적절히 제어되는지 검증

### 전제조건
- 로그아웃 상태에서 시작

### 테스트 단계
1. **로그아웃 상태 테스트**
   - 사이드바 하단에 "로그인" 버튼 표시 확인
   - "내가 수집한 카페" 클릭 시 처리 확인
   - "북마크한 카페" 클릭 시 처리 확인

2. **로그인 처리**
   - "로그인" 버튼 클릭하여 로그인 페이지 이동
   - 테스트 계정으로 로그인 수행
   - 메인 페이지로 복귀 확인

3. **로그인 상태 테스트**
   - 사이드바 하단에 로그아웃 관련 UI 표시 확인
   - 모든 메뉴 정상 접근 확인
   - "내가 수집한 카페" 페이지 정상 로드 확인
   - "북마크한 카페" 페이지 정상 로드 확인

### 예상 결과
- 로그아웃 상태에서 적절한 접근 제어
- "로그인" 버튼이 명확히 표시됨
- 로그인 후 모든 기능 정상 접근 가능
- 보호된 페이지들이 정상 로드됨

### 실패 조건
- 접근 제어 누락
- 로그인 버튼 동작 실패
- 로그인 후 접근 여전히 차단
- 보호된 페이지 오류

## 시나리오 5: 로그아웃 기능

### 목적
로그인된 상태에서 로그아웃 기능이 정상적으로 동작하는지 검증

### 전제조건
- 로그인된 사용자 상태
- 메인 페이지 접속

### 테스트 단계
1. 사이드바 하단의 로그아웃 버튼 또는 메뉴 확인
2. 로그아웃 버튼 클릭
3. 로그아웃 확인 메시지 (있는 경우) 처리
4. 로그아웃 완료 후 페이지 상태 확인
5. 사이드바 하단 "로그인" 버튼 표시 확인
6. 보호된 페이지 접근 시 차단 확인

### 예상 결과
- 로그아웃 버튼이 명확히 표시됨
- 클릭 시 즉시 로그아웃 처리
- 사이드바가 로그아웃 상태로 변경
- 보호된 페이지 접근이 다시 차단됨

### 실패 조건
- 로그아웃 버튼 누락
- 로그아웃 처리 실패
- 상태 변경 미반영
- 세션 정리 불완전

## 시나리오 6: 메뉴 개수 표시 동기화

### 목적
사이드바에 표시되는 검색 결과 및 추천 카페 개수가 실제와 일치하는지 검증

### 전제조건
- 메인 페이지 접속 상태

### 테스트 단계
1. **검색 결과 개수 확인**
   - 사이드바의 "검색 결과 N개" 표시 확인
   - 검색 페이지 이동하여 실제 개수 확인
   - 새로운 검색 수행 후 개수 변화 확인

2. **추천 카페 개수 확인**
   - 사이드바의 "개발자가 추천하는 카페 N개" 표시 확인
   - 추천 페이지 이동하여 실제 개수 확인
   - 카테고리 필터링 후에도 사이드바는 전체 개수 유지 확인

3. **실시간 업데이트 확인**
   - 페이지 이동 시 개수 실시간 반영
   - 새로고침 후에도 정확한 개수 유지

### 예상 결과
- 사이드바 개수와 실제 페이지 개수 일치
- 검색 실행 시 검색 결과 개수 즉시 업데이트
- 추천 카페 개수는 전체 기준으로 고정
- 모든 상황에서 정확한 개수 표시

### 실패 조건
- 개수 표시 불일치
- 실시간 업데이트 실패
- 새로고침 시 개수 초기화
- 잘못된 개수 계산

## 시나리오 7: 사이드바 반응형 동작

### 목적
다양한 화면 크기에서 사이드바가 적절히 동작하는지 검증

### 전제조건
- 브라우저 개발자 도구로 화면 크기 조절 가능

### 테스트 단계
1. **데스크톱 화면 (1280px 이상)**
   - 사이드바 고정 표시 확인
   - 모든 메뉴 완전 표시 확인

2. **태블릿 화면 (768px-1024px)**
   - 사이드바 동작 방식 확인
   - 메뉴 접근 방법 확인

3. **모바일 화면 (375px 이하)**
   - 햄버거 메뉴 또는 숨김 처리 확인
   - 모바일 네비게이션 대안 확인
   - 터치 친화적 인터페이스 확인

### 예상 결과
- 각 화면 크기에 최적화된 사이드바 표시
- 모바일에서도 모든 메뉴 접근 가능
- 터치 인터페이스에 적합한 크기 및 간격
- 부드러운 반응형 전환

### 실패 조건
- 특정 화면 크기에서 사이드바 깨짐
- 모바일에서 메뉴 접근 불가
- 터치 요소 크기 부적절
- 반응형 전환 문제

## 시나리오 8: 키보드 네비게이션 및 접근성

### 목적
키보드만으로 사이드바의 모든 기능을 사용할 수 있는지 검증

### 전제조건
- 메인 페이지 접속 상태
- 키보드 네비게이션 테스트 환경

### 테스트 단계
1. **탭 네비게이션**
   - Tab 키로 사이드바 요소 간 이동
   - 포커스 인디케이터 표시 확인
   - 논리적 순서로 포커스 이동 확인

2. **엔터/스페이스 키 동작**
   - 메뉴 항목에서 Enter 키로 페이지 이동
   - 버튼에서 Space 키 동작 확인

3. **검색 필드 키보드 동작**
   - Tab으로 검색 필드 포커스
   - Enter 키로 검색 실행
   - Escape 키로 포커스 해제

### 예상 결과
- 모든 사이드바 요소가 키보드로 접근 가능
- 명확한 포커스 인디케이터 표시
- 키보드 단축키 적절히 동작
- 논리적이고 직관적인 네비게이션 순서

### 실패 조건
- 키보드 접근 불가 요소 존재
- 포커스 인디케이터 누락
- 키보드 동작 실패
- 네비게이션 순서 혼란
