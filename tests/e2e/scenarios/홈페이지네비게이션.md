# 홈페이지 네비게이션 테스트 시나리오

## 개요

홈페이지(/)에서 제공하는 주요 네비게이션 버튼들의 동작을 검증하는 시나리오입니다.

## 우선순위

**Critical (P0)** - 사용자 진입점이므로 최우선 테스트 필요

## 시나리오 1: 메인 입장하기 버튼 동작 검증

### 목적

홈페이지의 "입장하기" 버튼 클릭 시 올바르게 메인 페이지로 이동하는지 검증

### 전제조건

- 브라우저가 열려있음
- 인터넷 연결 상태 양호

### 테스트 단계

1. `http://localhost:3000` 페이지 접속
2. 페이지 로딩 완료 대기
3. "입장하기" 버튼 존재 확인
4. "입장하기" 버튼 클릭
5. `/main` 페이지로 리다이렉트 확인

### 예상 결과

- 홈페이지가 정상적으로 로드됨
- "입장하기" 버튼이 화면에 표시됨
- 버튼 클릭 시 `/main` 경로로 이동
- 메인 페이지의 사이드바와 콘텐츠 영역이 정상 표시

### 실패 조건

- 홈페이지 로딩 실패
- "입장하기" 버튼 누락
- 버튼 클릭 시 다른 페이지로 이동
- 메인 페이지 로딩 실패

## 시나리오 2: 하단 "지금 시작하기" 버튼 동작 검증

### 목적

홈페이지 하단의 "지금 시작하기" 버튼이 동일하게 메인 페이지로 이동하는지 검증

### 전제조건

- 브라우저가 열려있음
- 홈페이지 접속 상태

### 테스트 단계

1. 홈페이지에서 하단으로 스크롤
2. "지금 시작하기" 버튼 존재 확인
3. "지금 시작하기" 버튼 클릭
4. `/main` 페이지로 리다이렉트 확인

### 예상 결과

- 하단 섹션까지 스크롤 가능
- "지금 시작하기" 버튼이 표시됨
- 버튼 클릭 시 `/main` 경로로 이동
- 두 버튼의 동작이 일치함

### 실패 조건

- 스크롤 동작 불가
- 하단 버튼 누락
- 상단 버튼과 다른 동작
- 페이지 이동 실패

## 시나리오 3: `<ContactCard/>` 버튼 동작 검증

### 목적

홈페이지 하단의 Contact Me. 아래의 버튼이 클릭 가능한지 확인

### 전제조건

- 브라우저가 열려있음
- 홈페이지 접속 상태

### 테스트 단계

1. 홈페이지에서 하단으로 스크롤
2. `aria-label={`${title} 버튼`}` 버튼 존재 확인
3. `aria-label={`${title} 버튼`}` 버튼 클릭
4. 클릭이 된다면 성공

### 예상 결과

- 하단 섹션까지 스크롤 가능
- `aria-label={`${title} 버튼`}` 버튼이 표시됨
- 두 버튼 모두 클릭이 가능

### 실패 조건

- 스크롤 동작 불가
- 클릭 불가(disabled)

## 시나리오 4: 반응형 디자인 검증

### 목적

다양한 화면 크기에서 네비게이션 요소들이 정상적으로 표시되고 동작하는지 검증

### 전제조건

- 브라우저 개발자 도구 사용 가능

### 테스트 단계

1. 데스크톱 해상도 (1280x720)에서 홈페이지 접속
2. "입장하기" 버튼 동작 확인
3. 태블릿 해상도 (768x1024)로 변경
4. 버튼 배치 및 동작 확인
5. 모바일 해상도 (375x667)로 변경
6. 버튼 배치 및 동작 확인

### 예상 결과

- 모든 해상도에서 버튼이 적절히 배치됨
- 텍스트가 깨지지 않고 읽기 가능함
- 모든 해상도에서 클릭/터치 동작 정상
- 반응형 레이아웃이 자연스럽게 적용됨

### 실패 조건

- 특정 해상도에서 버튼 누락
- 텍스트 오버플로우 또는 깨짐
- 버튼 클릭 영역 축소
- 레이아웃 깨짐
