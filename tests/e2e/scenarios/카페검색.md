# 카페 검색 기능 테스트 시나리오

## 개요
사용자가 카페를 검색하고 결과를 확인하는 기능을 검증하는 시나리오입니다.

## 우선순위
**Critical (P0)** - 서비스의 핵심 카페 발견 기능

## 시나리오 1: 기본 카페 검색

### 목적
검색어 입력을 통해 카페 목록이 정상적으로 표시되는지 검증

### 전제조건
- 메인 페이지 접속 상태
- 사이드바에서 "검색 결과" 메뉴 선택

### 테스트 단계
1. 검색 페이지 로드 확인
2. 검색 입력 필드 존재 확인
3. "성수" 키워드로 검색 수행
4. 검색 결과 목록 표시 확인
5. 결과 개수 표시 확인 (예: "45개의 검색 결과")
6. 카페 정보 표시 확인 (이름, 주소, 전화번호)

### 예상 결과
- 검색 페이지가 정상 로드됨
- 검색 입력 필드가 명확하게 표시됨
- 검색 실행 후 관련 카페 목록 표시
- 각 카페의 기본 정보 (이름, 주소, 전화번호) 표시
- 정확한 검색 결과 개수 표시

### 실패 조건
- 검색 페이지 로딩 실패
- 검색 기능 동작하지 않음
- 검색 결과 표시 오류
- 카페 정보 누락 또는 오류

## 시나리오 2: 검색 결과 페이지네이션

### 목적
다수의 검색 결과에 대한 페이지네이션이 정상 동작하는지 검증

### 전제조건
- 검색 결과가 한 페이지를 초과하는 키워드 사용
- 검색 결과 페이지 상태

### 테스트 단계
1. 많은 결과를 가진 검색어 입력 (예: "서울")
2. 첫 페이지 결과 확인
3. 페이지네이션 컨트롤 존재 확인
4. 다음 페이지(▶) 버튼 클릭
5. 두 번째 페이지 결과 로드 확인
6. 이전 페이지(◀) 버튼 클릭
7. 첫 페이지로 돌아가기 확인
8. 페이지 번호 표시 확인 (예: "1/3")

### 예상 결과
- 검색 결과가 적절한 수로 페이지 분할
- 페이지네이션 컨트롤이 명확하게 표시됨
- 페이지 이동 시 새로운 결과 정상 로드
- 현재 페이지 번호 및 전체 페이지 수 표시
- 부드러운 페이지 전환

### 실패 조건
- 페이지네이션 누락
- 페이지 이동 실패
- 중복 결과 표시
- 페이지 번호 오류

## 시나리오 3: 카페 상세 정보 모달

### 목적
검색 결과에서 특정 카페 클릭 시 상세 정보가 정상 표시되는지 검증

### 전제조건
- 검색 결과 페이지에 카페 목록 표시 상태

### 테스트 단계
1. 검색 결과 중 특정 카페 아이템 클릭
2. 카페 상세 정보 모달 표시 확인
3. 상세 정보 내용 확인:
   - 카페 이름
   - 위치 (주소)
   - 전화번호
   - 분류 (음식점/카페)
   - 영업시간
4. "수집하기" 버튼 존재 확인
5. "메뉴 보기" 버튼 및 메뉴 개수 확인
6. 모달 닫기 기능 확인 (ESC 키 또는 외부 클릭)

### 예상 결과
- 카페 클릭 시 모달이 즉시 표시됨
- 모든 카페 정보가 정확하게 표시됨
- "수집하기" 및 "메뉴 보기" 버튼 정상 표시
- 모달 닫기 기능 정상 동작
- 모달 닫은 후 검색 결과 페이지 유지

### 실패 조건
- 모달 표시 실패
- 카페 정보 누락 또는 오류
- 버튼 동작 실패
- 모달 닫기 불가

## 시나리오 4: 수집하기 기능 (로그인 필요)

### 목적
로그인하지 않은 상태에서 "수집하기" 버튼 클릭 시 적절한 처리가 되는지 검증

### 전제조건
- 로그아웃 상태
- 카페 상세 모달 표시 상태

### 테스트 단계
1. "수집하기" 버튼 클릭
2. 로그인 요구 메시지 또는 로그인 페이지 리다이렉트 확인
3. 로그인 후 원래 카페로 돌아오는지 확인 (옵션)

### 예상 결과
- "로그인이 필요합니다" 형태의 안내 메시지
- 로그인 페이지로 리다이렉트 또는 로그인 모달 표시
- 로그인 완료 후 사용자 친화적인 플로우 제공

### 실패 조건
- 로그인 체크 누락
- 에러 메시지 부적절
- 로그인 후 플로우 단절

## 시나리오 5: 메뉴 보기 기능

### 목적
"메뉴 보기" 버튼 클릭 시 카페 메뉴 정보가 정상 표시되는지 검증

### 전제조건
- 카페 상세 모달 표시 상태
- 메뉴 정보가 있는 카페 선택

### 테스트 단계
1. "메뉴 보기 (N개)" 버튼 클릭
2. 메뉴 목록 표시 확인
3. 메뉴 정보 내용 확인 (이름, 가격 등)
4. 메뉴 목록에서 뒤로가기 확인

### 예상 결과
- 메뉴 목록이 명확하게 표시됨
- 각 메뉴의 상세 정보 확인 가능
- 표시된 메뉴 개수와 실제 개수 일치
- 직관적인 네비게이션 제공

### 실패 조건
- 메뉴 정보 로딩 실패
- 메뉴 개수 불일치
- 메뉴 정보 누락
- 네비게이션 문제

## 시나리오 6: 검색 성능 및 사용자 경험

### 목적
검색 기능의 성능과 사용자 경험이 적절한지 검증

### 전제조건
- 검색 페이지 접속 상태

### 테스트 단계
1. **검색 응답 시간 측정**
   - 다양한 키워드로 검색 수행
   - 응답 시간이 3초 이내인지 확인

2. **빈 검색어 처리**
   - 검색어 없이 검색 시도
   - 적절한 안내 메시지 확인

3. **특수문자 검색어 처리**
   - 특수문자 포함 검색어 테스트
   - 시스템 오류 없이 처리되는지 확인

4. **검색 결과 없음 처리**
   - 존재하지 않는 검색어 입력
   - "검색 결과가 없습니다" 형태의 메시지 확인

### 예상 결과
- 모든 검색이 3초 이내 완료
- 빈 검색어에 대한 적절한 가이드
- 특수문자 안전하게 처리
- 결과 없음 상황의 명확한 안내

### 실패 조건
- 검색 응답 시간 과도하게 느림
- 빈 검색어 처리 부적절
- 특수문자로 인한 시스템 오류
- 결과 없음 상황 처리 미흡

## 시나리오 7: 모바일 반응형 검색

### 목적
모바일 환경에서 검색 기능이 정상적으로 동작하는지 검증

### 전제조건
- 모바일 화면 크기 설정 (375x667)

### 테스트 단계
1. 모바일 화면에서 검색 페이지 접속
2. 검색 입력 필드 터치 및 키보드 표시 확인
3. 가상 키보드 상태에서 화면 레이아웃 확인
4. 검색 결과 목록의 터치 스크롤 확인
5. 카페 아이템 터치로 상세 모달 표시 확인
6. 모달의 터치 네비게이션 확인

### 예상 결과
- 모바일에 최적화된 검색 인터페이스
- 가상 키보드와 화면 레이아웃 조화
- 터치 친화적인 요소 크기 및 간격
- 부드러운 터치 스크롤 및 네비게이션

### 실패 조건
- 모바일 최적화 부족
- 가상 키보드로 인한 레이아웃 깨짐
- 터치 요소 크기 부적절
- 스크롤 및 네비게이션 문제
