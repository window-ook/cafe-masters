# 북마크 기능 테스트 시나리오

## 개요
사용자가 나중에 방문하고 싶은 카페를 북마크하고 관리하는 기능을 검증하는 시나리오입니다.

## 우선순위
**High (P1)** - 사용자 편의성을 위한 중요 기능

## 시나리오 1: 카페 북마크 추가

### 목적
검색 또는 추천 카페에서 북마크 추가가 정상적으로 동작하는지 검증

### 전제조건
- 사용자 로그인 완료
- 검색 결과 또는 추천 카페 페이지 접속
- 카페 상세 모달 또는 상세 페이지 표시

### 테스트 단계
1. 카페 상세 정보에서 북마크 버튼 존재 확인
2. 북마크 버튼 클릭 (빈 하트 또는 별 아이콘)
3. 북마크 추가 성공 피드백 확인
4. 버튼 상태 변경 확인 (채워진 하트 또는 별 아이콘)
5. 북마크 페이지에서 추가된 카페 확인
6. 북마크 개수 증가 확인

### 예상 결과
- 북마크 버튼이 명확하게 표시됨
- 클릭 시 즉시 북마크 추가 처리
- 성공 메시지 또는 토스트 알림 표시
- 버튼 시각적 상태 즉시 변경
- 북마크 목록에 새 카페 추가
- 실시간 개수 업데이트

### 실패 조건
- 북마크 버튼 누락
- 북마크 추가 처리 실패
- 피드백 메시지 부재
- 상태 변경 미반영
- 목록 업데이트 실패

## 시나리오 2: 북마크 제거

### 목적
이미 북마크된 카페에서 북마크 제거가 정상적으로 동작하는지 검증

### 전제조건
- 북마크된 카페가 있는 사용자 계정
- 북마크된 카페의 상세 정보 접근

### 테스트 단계
1. 이미 북마크된 카페 상세 정보 접근
2. 북마크 버튼 상태 확인 (채워진 아이콘)
3. 북마크 버튼 클릭
4. 북마크 제거 확인 메시지 (옵션)
5. 버튼 상태 변경 확인 (빈 아이콘)
6. 북마크 페이지에서 카페 제거 확인
7. 북마크 개수 감소 확인

### 예상 결과
- 북마크된 카페의 버튼 상태 정확히 표시
- 클릭 시 즉시 북마크 제거 처리
- 확인 메시지 또는 직접 제거 (UX 정책에 따라)
- 버튼 상태 즉시 변경
- 북마크 목록에서 카페 제거
- 실시간 개수 업데이트

### 실패 조건
- 북마크 상태 표시 오류
- 제거 처리 실패
- 상태 변경 미반영
- 목록 업데이트 지연
- 데이터 불일치

## 시나리오 3: 북마크 페이지 관리

### 목적
북마크 전용 페이지에서 북마크된 카페들을 효과적으로 관리할 수 있는지 검증

### 전제조건
- 여러 카페가 북마크된 사용자 계정
- 사이드바에서 "북마크한 카페" 메뉴 클릭

### 테스트 단계
1. 북마크 페이지(`/bookmark`) 로드 확인
2. 북마크된 카페 목록 표시 확인
3. 각 카페 정보 표시 확인:
   - 카페 이름
   - 주소
   - 전화번호
   - 북마크 날짜 (옵션)
4. 지역 필터 기능 테스트
5. 카페 아이템 클릭 시 상세 페이지 이동 확인
6. 북마크 페이지에서 직접 북마크 제거 테스트

### 예상 결과
- 북마크 페이지가 정상 로드됨
- 모든 북마크된 카페가 목록에 표시
- 카페 기본 정보가 명확히 표시
- 지역별 필터링 기능 정상 동작
- 카페 클릭 시 상세 페이지로 이동
- 페이지 내에서 북마크 관리 가능

### 실패 조건
- 페이지 로딩 실패
- 북마크 목록 누락
- 카페 정보 부정확
- 필터 기능 동작 실패
- 네비게이션 문제

## 시나리오 4: 북마크 상태 동기화

### 목적
여러 페이지 간 북마크 상태가 실시간으로 동기화되는지 검증

### 전제조건
- 사용자 로그인 상태
- 여러 브라우저 탭 또는 창 열기 가능

### 테스트 단계
1. **같은 브라우저 내 동기화**
   - 검색 페이지에서 카페 북마크 추가
   - 북마크 페이지로 이동하여 추가 확인
   - 북마크 페이지에서 북마크 제거
   - 검색 페이지로 돌아가서 상태 확인

2. **페이지 새로고침 후 상태 유지**
   - 북마크 추가 후 페이지 새로고침
   - 북마크 상태 유지 확인

3. **세션 지속성**
   - 북마크 추가 후 브라우저 종료
   - 재접속 시 북마크 상태 유지 확인

### 예상 결과
- 모든 페이지에서 북마크 상태 실시간 동기화
- 새로고침 후에도 상태 유지
- 세션 종료 후 재접속 시 데이터 복원
- 일관된 사용자 경험 제공

### 실패 조건
- 페이지 간 상태 불일치
- 새로고침 시 상태 초기화
- 세션 지속성 부족
- 데이터 동기화 지연

## 시나리오 5: 북마크에서 수집으로 전환

### 목적
북마크된 카페를 방문 후 수집으로 전환하는 플로우가 자연스럽게 동작하는지 검증

### 전제조건
- 북마크된 카페가 있는 사용자 계정
- 북마크 상세 페이지 접근

### 테스트 단계
1. 북마크 목록에서 카페 클릭
2. 북마크된 카페 상세 페이지(`/bookmark/detail/[id]`) 이동
3. "수집하기" 버튼 존재 확인
4. "수집하기" 버튼 클릭하여 평점 입력
5. 수집 완료 후 북마크 상태 확인:
   - 북마크 유지 또는 자동 제거 (정책에 따라)
6. 컬렉션 페이지에서 수집된 카페 확인

### 예상 결과
- 북마크 상세 페이지 정상 접근
- "수집하기" 기능 정상 동작
- 수집 후 북마크 처리 정책 일관성
- 컬렉션에 카페 정상 추가
- 사용자 플로우 자연스러움

### 실패 조건
- 상세 페이지 접근 실패
- 수집 기능 동작 실패
- 북마크/수집 상태 충돌
- 데이터 불일치

## 시나리오 6: 로그인 상태에 따른 북마크 처리

### 목적
로그인하지 않은 상태에서 북마크 시도 시 적절한 처리가 되는지 검증

### 전제조건
- 로그아웃 상태
- 검색 결과 또는 추천 카페 접근

### 테스트 단계
1. 로그아웃 상태에서 카페 상세 정보 접근
2. 북마크 버튼 존재 및 상태 확인
3. 북마크 버튼 클릭
4. 로그인 요구 메시지 또는 리다이렉트 확인
5. 로그인 후 원래 카페로 돌아오는지 확인
6. 로그인 후 북마크 기능 정상 동작 확인

### 예상 결과
- 로그아웃 상태에서도 북마크 버튼 표시
- 클릭 시 로그인 요구 안내
- 로그인 페이지로 적절한 리다이렉트
- 로그인 후 원래 위치로 복귀
- 로그인 후 북마크 기능 즉시 사용 가능

### 실패 조건
- 비로그인 상태 처리 부적절
- 로그인 요구 안내 부족
- 로그인 후 플로우 단절
- 사용자 경험 혼란

## 시나리오 7: 북마크 성능 및 사용자 경험

### 목적
북마크 기능의 응답성과 사용자 경험이 만족스러운지 검증

### 전제조건
- 사용자 로그인 상태
- 다양한 네트워크 환경 시뮬레이션 가능

### 테스트 단계
1. **응답 시간 테스트**
   - 북마크 추가/제거 응답 시간 측정
   - 1초 이내 처리 확인

2. **대량 북마크 처리**
   - 다수의 카페를 북마크
   - 목록 로딩 성능 확인

3. **오프라인/온라인 전환**
   - 오프라인 상태에서 북마크 시도
   - 온라인 복구 시 동기화 확인

4. **시각적 피드백**
   - 북마크 버튼 애니메이션
   - 로딩 상태 표시
   - 성공/실패 피드백

### 예상 결과
- 모든 북마크 동작이 1초 이내 완료
- 대량 데이터에서도 부드러운 성능
- 오프라인 상황 적절히 처리
- 직관적이고 만족스러운 시각적 피드백

### 실패 조건
- 응답 시간 과도하게 느림
- 대량 데이터 처리 성능 저하
- 오프라인 상황 미처리
- 시각적 피드백 부족
