### 앱 소개

카페 마스터즈는 카페러버들을 위해 만든 앱이에요. <br />
전국에 있는 카페를 검색할 수 있고, 내가 갔던 카페에 대해 메모할 수 있는데 <br />
그냥 메모하면 재미가 없잖아요? 이걸 카드로 수집할 수 있어요. <br />
카드를 수집할 때마다 티어도 올라가고, 특정 카페는 유니크 카드를 주기도 합니다. 잘 찾아보세요😊
